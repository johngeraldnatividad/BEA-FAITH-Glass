# Bea Faith website (React + Vite)

```
npm install
npm run dev      # local preview, auto-refresh
npm run build    # production files in /dist
```

- All client text (phone, address, services, projects, steps) is in `src/data/content.js`
- Colors are CSS variables at the top of `src/styles.css`
- Put photos in `public/images/` and use `<img src="/images/name.jpg" alt="..." />` in place of the gray placeholder blocks
